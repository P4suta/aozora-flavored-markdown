# Aozora Flavored Markdown

Rust Markdown parser and renderer with Aozora Bunko typography.

## Install

```sh
cargo install aozora-flavored-markdown-cli --locked
```

## Usage

```sh
aozora-flavored-markdown render input.md
```

The [crate guide](crates/aozora-flavored-markdown/README.md) describes notation, rendering options, and measured conformance.
See the [API reference](https://docs.rs/aozora-flavored-markdown) for Rust library use.
